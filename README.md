# 🚨 골든타임 세이프맵 (GoldenTime SafeMap)

> **공공 안전시설 위치 데이터 전처리와 최단경로 분석을 통한 응급시설(AED, 소화기, 소화전) 긴급 탐색 시스템**

### 🌐 GitHub Pages 서비스 바로가기
👉 **[https://pierrvel.github.io/safemap-/](https://pierrvel.github.io/safemap-/)**

---

## 📌 주요 기능
1. **실시간 공공데이터포털 연동**: 국립중앙의료원 전국 자동심장충격기(AED) 위치 데이터 실시간 API 호출
2. **구글맵(Google Maps) & 오픈맵 듀얼 엔진**: 사용자 GPS 위치 자동 감지, 최단거리 장비 황금색 하이라이트 및 유도 경로선(Polyline) 시각화
3. **데이터 전처리 알고리즘**:
   - 위·경도 결측치 및 비정상 좌표 자동 필터링
   - 소화기 10년 내구연한 경과 장비 필터링
   - AED 일련번호 기반 노후도 및 현재 시각 기준 운영시간 외 폐쇄 장비 판별
4. **긴급 대응 중심 UI/UX**:
   - 최단거리 장비까지의 거리(m) 및 도보 도달 시간(골든타임 4분 내 여부 판정)
   - **건물 내부 상세 설치 위치(예: 1층 로비, 지하 3층 안내데스크 앞)** 최우선 강조
   - 🚨 119 긴급통화 / 🧭 Google 도보 길안내 / 📞 관리처 통화 / ⚠️ 현장 이상 제보 시스템
5. **응급 행동 가이드**: CPR 4단계 요령 및 소화기 PASS 사용법 안내
