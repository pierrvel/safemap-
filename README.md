# 🚨 골든타임 세이프맵 (GoldenTime SafeMap)

> **공공 안전시설(AED · 민방위 대피소) 실시간 위치 탐색 및 보행자 긴급 길안내 시스템**  
> 심정지 등 응급 상황에서 주변의 자동심장충격기(AED)와 비상시 민방위 대피시설을 신속하고 정확하게 찾을 수 있도록 지원하는 웹 애플리케이션(PWA)입니다.

### 🌐 공식 웹 서비스 바로가기
👉 **[https://prompt-bismuth-avyohx5.vercel.app](https://prompt-bismuth-avyohx5.vercel.app)**

---

## 📌 주요 핵심 기능

### 1. 실시간 자동심장충격기(AED) 탐색
- **공공데이터포털 실시간 연동**: 국립중앙의료원 중앙응급의료센터 API를 실시간 호출하여 사용자 반경 내 AED 장비 정보 조회.
- **운영시간 기반 개방 여부 실시간 판정**: 요일별/공휴일 운영시간 및 현재 KST 시각을 비교하여 '지금 이용 가능', '이용 불가(영업 외)', '운영시간 미확인' 상태를 정확히 구분 표기.
- **건물 내부 상세 설치 위치 최우선 노출**: "1층 로비 안내데스크 앞", "관리사무소 입구" 등 분초를 다투는 응급 상황에서 바로 찾을 수 있도록 내부 위치 강조.

### 2. 민방위 대피시설 탐색
- **행정안전부 대피시설 공공데이터 연동**: 비상사태 및 재난 시 이용 가능한 민방위 대피소 위치 및 대피 면적(㎡) 안내.
- **수용 공간 정보 제공**: 지상/지하 층수 구분 및 공인된 대피 면적을 기반으로 안내.

### 3. 카카오맵 연동 & 마커 스파이더파이(Spiderfier)
- **공공데이터 원본 좌표 100% 보존**: 대단지 아파트나 복합 단지 내 여러 동에 분산 설치된 장비의 고유 좌표를 임의로 통합하지 않고 동별 고유 위치를 보존.
- **인접 마커 겹침 방사형 펼침(Spiderfier)**: 동일 건물 또는 15m 이내 초근접 장비가 있을 경우 클러스터 핀으로 표시되며, 터치 시 방사형 다리로 펼쳐져 개별 장비를 명확히 확인하고 선택 가능.

### 4. OSRM 보행자 최단 경로 및 길안내
- **실제 보행 도로망 기반 경로(Polyline)**: OpenStreetMap 보행자 경로 엔진(OSRM routed-foot)을 통해 도보 이동 경로선 시각화.
- **도보 소요 시간 산출**: 보행 거리(m) 및 소요 시간(초/분) 제공, 카카오맵 길찾기 딥링크 원터치 연동.

### 5. PWA (Progressive Web App) 앱 설치 지원
- Android Chrome/Samsung Internet 및 iOS Safari 홈 화면 추가 완벽 지원.
- 브라우저 주소창 없는 독립 창(Standalone) 모드 구동.
- 서비스 워커(Service Worker) 기반 셸 캐싱을 통해 네트워크 지연 상황에서도 신속한 초기 로딩 보장.

### 6. CPR 심폐소생술 메트로놈
- 응급 상황 시 분당 110회 표준 압박 템포에 맞춘 시각·청각·햅틱(진동) 비트 가이드 제공.

## 🛡️ 신뢰성 및 데이터 정제 원칙 (Reliability & Data Integrity)

본 프로젝트는 현장 응급 구조의 신뢰성을 최우선으로 하여 다음과 같은 데이터 정제 기준을 엄격히 준수합니다.

1. **서울시청 기본 좌표 오표기 및 비동기 레이스 컨디션 차단**:
   - Geolocation 위치 수신 전까지 임의 좌표를 사용하지 않으며, 위치 권한 거부 시 명확한 안내 문구를 표시합니다.
   - 요청 시퀀스 식별자를 통해 지연 응답이 최신 위치 데이터를 덮어쓰는 레이스 컨디션을 원천 차단했습니다.
2. **공공데이터 원본 좌표 보존**:
   - 주소 지오코딩으로 아파트 단지 대표 지번으로 좌표를 덮어쓰지 않고, 공공데이터에 등록된 개별 장비의 위·경도를 온전히 유지합니다.
3. **운영시간 판정 단일화 및 모순 제거**:
   - 요일별 시작/종료 시각(숫자/문자열 타입 불일치 등)을 정규화하여 '24시간 상시 개방'과 '이용 불가'가 동시에 표시되는 논리적 모순을 0건으로 정제했습니다.
4. **출처 불명 및 허위·과장 문구 배제**:
   - 공인되지 않은 임의의 내구연한(8년 노후 판정 등) 및 출처 불명의 대표번호를 제거했습니다.
   - 공식 서비스 준비 중인 제보·점검 기능은 안내 모달을 통해 이용자에게 사실대로 투명하게 고지합니다.
5. **데이터 출처 및 기준일 상시 공개**:
   - 헤더의 `[ ℹ️ 출처·주의 ]` 버튼을 통해 국립중앙의료원, 행정안전부 등 데이터 출처와 기준일을 누구나 열람할 수 있습니다.

## ⚠️ 응급 상황 시 필수 주의사항 (Disclaimer)

> **심정지 및 생명 위급 상황에서는 반드시 `119` 신고가 최우선입니다.**

- 본 서비스의 AED 및 대피소 정보는 공공데이터포털(국립중앙의료원 중앙응급의료센터 및 행정안전부)에서 제공하는 원본 데이터를 바탕으로 제공됩니다.
- 시설의 내부 공사, 운영 정책 변경, 잠금장치 설치, 이전/철거 등으로 인해 실제 현장 상황과 일부 차이가 발생할 수 있습니다.
- 민방위 대피소는 전시·사변 등 국가 비상사태 시 주민 대피를 목적으로 지정된 시설이며, 평시 개방 여부는 시설 관리 주체(아파트, 상가, 지하철 등)의 운영 방침에 따릅니다.
- OpenStreetMap 보행자 라우팅은 오픈소스 커뮤니티 정책(FOSSGIS)에 따라 제공되며, 네트워크 장애 시 직선거리 기반 추정 경로로 자동 안전 전환(Fallback)됩니다.

## 🚀 로컬 개발 환경 설정 (Local Development)

### 1. 패키지 설치
```bash
npm install
```

### 2. 환경변수 설정 (`.env`)
프로젝트 루트 경로에 `.env` 파일을 생성하고 필요한 API 키를 입력합니다:
```env
KAKAO_MAP_API_KEY=your_kakao_javascript_key
KAKAO_REST_API_KEY=your_kakao_rest_api_key
DATA_GO_KR_KEY=your_data_go_kr_decoding_key
PORT=3000
```

### 3. 로컬 서버 실행
```bash
# Vite 클라이언트 번들 빌드
npm run build

# Express 백엔드 및 정적 파일 서버 구동
node server.js
```
브라우저에서 `http://localhost:3000` 접속.
