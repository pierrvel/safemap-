# 🚨 골든타임 세이프맵 (GoldenTime SafeMap)

> **공공 안전시설(AED · 민방위 대피소) 실시간 위치 탐색 및 보행자 긴급 길안내 시스템**  
> 심정지 등 분초를 다투는 응급 상황에서 주변의 자동심장충격기(AED)와 비상시 민방위 대피시설을 신속하고 정확하게 찾을 수 있도록 지원하는 웹 애플리케이션(PWA)입니다.

### 🌐 공식 웹 서비스 바로가기
👉 **[https://prompt-bismuth-avyohx5.vercel.app](https://prompt-bismuth-avyohx5.vercel.app)**

## 📌 주요 핵심 기능 (Key Features)

### 1. 실시간 자동심장충격기(AED) 정밀 탐색 & 개방 여부 판정
- **공공데이터포털 실시간 연동**: 국립중앙의료원 중앙응급의료센터 API를 실시간 호출하여 사용자 반경 내 AED 장비 정보 조회.
- **운영시간 기반 개방 여부 일원화 판정**: 요일별 운영시간(자정을 넘기는 야간 운영 포함)과 KST 현재 시각을 교차 분석하여 '지금 이용 가능', '이용 불가(영업 외)', '운영시간 정보 없음' 상태를 모순 없이 명확히 구분 표기.
- **건물 내부 상세 설치 위치 최우선 노출**: "관리사무소 1층 벽면", "1층 로비 안내데스크 앞" 등 응급 상황에서 현장에 도착해 헤매지 않도록 상세 위치 강조.

### 2. 지능형 3단계 위치 보정 & 데이터 정제 파이프라인
공공데이터의 필지 오차와 원천 좌표 오염을 원천 차단하기 위한 3단계 정밀 보정 시스템을 탑재했습니다:
- **1단계: 상세위치 기반 초정밀 세부위치 보정 (`Sub-location Calibration`)**:
  - `buildPlace`("관리사무소 1층", "101동", "별관", "경로당" 등)에서 세부 키워드를 자동 추출.
  - 아파트 단지 브랜드 일치(`verifyStrictBrandMatch`) 검증을 거쳐 단지 중심이 아닌 실제 관리동/세부 건물 위치로 핀을 초정밀 이전하고 `✨ [건물명] 보정됨` 배지 부여.
- **2단계: 지번/필지 오차 지오코딩 보정 (`Building Geocoding`)**:
  - 70m 이상 편차 발생 시 공공데이터 지번 오차를 카카오 건물/도로명 정밀 실측 좌표로 보정.
- **3단계: 공공데이터 원천 좌표 오염 격리 및 광역 행정구역 교차 검증 (`Regional Cross-Validation`)**:
  - 텍스트 주소와 검색 지역의 광역 시·도(`sido`, `sigungu`) 교차 검증(`isRegionalConflict`). 충돌 시 바로 제외하지 않고 텍스트 주소 지오코딩으로 실제 위치를 검증하여, 시·도 경계 인근(대전-세종, 부산-양산 등)의 정상 시설은 유지.
  - 점진적 지오코딩(`Progressive Geocoding`)으로 시골/미등록 지번도 도로/읍면동 단위 좌표 확보. 단, 70m 단위 정밀 보정에는 건물 단위로 정확히 일치한 좌표만 사용하고, 도로·읍면동 단위 근사 좌표는 원천 오염 복원에만 사용하며 `위치 확인 필요`로 표시.
  - 5km 이상 괴리 발생 시 오염된 공공데이터 원본 좌표를 버리고 실측 주소 좌표로 강제 복원(`OUTLIER_RESTORED`)하며, 사용자 검색 반경(5km) 초과 시 자동 격리하여 타지역 유령 핀(예: 여주교도소 좌표 오염 사례) 원천 배제.

### 3. 초근접 마커 스파이더파이 (Spiderfier)
- **동일 건물/초근접(20m 이내) 핀 방사형 펼침**: 같은 건물이나 단지 내 복수 장비가 겹쳐 있을 때 클러스터 핀을 터치하면 방사형 다리(Spider Legs)로 펼쳐져 모든 장비를 개별 확인 및 선택 가능.
- **즉각적인 선택 인터랙션**: 펼쳐진 자식 핀 터치 시 즉시 해당 장비로 카드가 전환되며, 외부 터치 또는 클러스터 재터치 시 깔끔하게 축소 복귀.

### 4. PWA (Progressive Web App) 앱 설치 & 단독 창 실행
- **전 플랫폼 홈 화면/바탕화면 설치**: Android(Chrome, 삼성 인터넷), iPhone/iPad(iOS Safari 홈 화면 추가), PC(Windows, Mac Chrome/Edge) 지원.
- **단독 창(Standalone) 모드 구동**: 브라우저 주소창과 툴바 없이 네이티브 앱과 동일하게 독립 창으로 실행.
- **서비스 워커(Service Worker) 캐싱**: Cache-First 셸 캐시와 Network-First API 캐싱 전략으로 네트워크 지연 상황에서도 신속한 초기 로딩 보장.

### 5. OSRM 보행자 최단 경로 및 실시간 길안내
- **실제 도보 도로망 기반 경로(Polyline)**: OpenStreetMap 보행자 경로 엔진(OSRM routed-foot)을 통해 도보 이동 경로선 시각화.
- **보행 소요 시간 산출**: 보행 거리(m) 및 소요 시간(초/분) 제공, 카카오맵 길찾기 원터치 딥링크 연동.

### 6. CPR 심폐소생술 105BPM 메트로놈
- 응급 상황 시 미국심장협회(AHA) 및 대한심폐소생협회 권고 템포(분당 100~120회)에 맞춘 105BPM 시각(깜빡임)·청각(비프음) 비트 가이드 제공.

### 7. 민방위 대피시설 실시간 탐색
- **행정안전부 대피시설 공공데이터 연동**: 전국 18,800여 개소 민방위 대피시설 위치, 대피 면적(㎡), 지상/지하 층수 안내.
- **한국 위도 경도폭 보정**: 위도에 따른 경도 폭 `cos(위도)` 정밀 계산으로 동서쪽 시설 누락 원천 차단.

## 🛡️ 신뢰성 및 데이터 정제 원칙 (Reliability & Data Integrity)

본 프로젝트는 현장 응급 구조의 신뢰성을 최우선으로 하여 다음과 같은 데이터 정제 기준을 엄격히 준수합니다.

1. **서울시청 기본 좌표 오표기 및 비동기 레이스 컨디션 차단**:
   - Geolocation 위치 수신 전까지 임의 좌표를 사용하지 않으며, 위치 권한 거부 시 명확한 안내 문구를 표시합니다.
   - 요청 시퀀스 식별자를 통해 지연 응답이 최신 위치 데이터를 덮어쓰는 레이스 컨디션을 원천 차단했습니다.
2. **엄격한 다계층 위치 보정 및 오염 데이터 격리**:
   - 아파트 단지명 브랜드 검증(`verifyStrictBrandMatch`)을 통해 상가/타단지 오매칭을 방지하고, 상세위치가 명시된 경우에만 정확한 관리동으로 보정합니다.
   - 공공데이터 원천 데이터의 시·도 오기재는 광역 교차 검증을 통해 실측 주소지로 강제 복원 및 격리합니다.
3. **운영시간 판정 단일화 및 모순 제거**:
   - 요일별 시작/종료 시각을 단일 통합 함수(`calculateAedOperatingInfo`)에서 정규화하여 '24시간 상시 개방'과 '이용 불가'가 동시에 표시되는 논리적 모순을 0건으로 정제했습니다.
4. **출처 불명 및 허위·과장 문구 배제**:
   - 공인되지 않은 임의의 내구연한(8년 노후 판정 등) 및 출처 불명의 대표번호를 제거했습니다.
   - 공식 서비스 준비 중인 제보·점검 기능은 안내 모달을 통해 이용자에게 사실대로 투명하게 고지하며, 인증되지 않은 제보는 시설 추천·필터 판단에 반영하지 않습니다.
5. **데이터 출처 및 기준일 상시 공개**:
   - 헤더의 `[ ℹ️ 출처·주의 ]` 버튼을 통해 국립중앙의료원, 행정안전부 등 데이터 출처와 기준일을 누구나 열람할 수 있습니다.

## ⚠️ 응급 상황 시 필수 주의사항 (Disclaimer)

> **심정지 및 생명 위급 상황에서는 반드시 `119` 신고가 최우선입니다.**

- 본 서비스의 AED 및 대피소 정보는 공공데이터포털(국립중앙의료원 중앙응급의료센터 및 행정안전부)에서 제공하는 원본 데이터를 바탕으로 제공됩니다.
- 시설의 내부 공사, 운영 정책 변경, 잠금장치 설치, 이전/철거 등으로 인해 실제 현장 상황과 일부 차이가 발생할 수 있습니다.
- 민방위 대피소는 전시·사변 등 국가 비상사태 시 주민 대피를 목적으로 지정된 시설이며, 평시 개방 여부는 시설 관리 주체(아파트, 상가, 지하철 등)의 운영 방침에 따릅니다.
- OpenStreetMap 보행자 라우팅은 오픈소스 커뮤니티 정책(FOSSGIS)에 따라 제공되며, 네트워크 장애 시 직선거리 기반 추정 경로로 자동 안전 전환(Fallback)됩니다.

## 🚀 로컬 개발 환경 설정 (Local Development)

### 1. 패키지 설치
```bash
npm install
```

### 2. 환경변수 설정 (`.env`)
프로젝트 루트 경로에 `.env` 파일을 생성하고 필요한 API 키를 입력합니다:
```env
KAKAO_MAP_API_KEY=your_kakao_javascript_key
KAKAO_REST_API_KEY=your_kakao_rest_api_key
DATA_GO_KR_KEY=your_data_go_kr_decoding_key
PORT=3000
```

### 3. 로컬 서버 실행
```bash
# Vite 클라이언트 번들 빌드
npm run build

# Express 백엔드 및 정적 파일 서버 구동
node server.js
```
브라우저에서 `http://localhost:3000` 접속.
