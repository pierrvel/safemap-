## 🧭 화면 구성과 사용 흐름 (UX)

판단 우선순위는 **1. 직관성, 2. 실용성·간단명료**입니다. 화면 하나에 질문 하나, 답 하나만 둡니다.

| 단계 | 화면 |
|---|---|
| 위치 허용 | 위치 권한을 묻는 첫 화면. 거부해도 주소 검색으로 찾을 수 있고, 아래에 항상 `119`와 `CPR 도와줘요`가 있음 |
| 첫 화면 | 하단 카드 맨 위에 **"AED까지 걸어서 약 N분"** 한 줄 답, 지도에는 빨간 핀과 도보 경로 미리보기·시간 말풍선 |
| 행동 | `[119]` `[안내 시작]` / `[CPR 도와줘요]` `[옆 사람에게 부탁]`(AED 위치 공유) |
| 자세히 | 장소를 누르면 주소·운영시간·설치 위치 보정 내역·카카오맵 링크 |
| 목록 | "주변 AED N곳 모두 보기" 또는 카드를 위로 밀기 |
| 카드 접기 | 손잡이를 누르거나 아래로 밀면 답 한 줄 + `119`만 남고 지도가 넓어짐. 접힌 동안 주변 AED 핀이 진한 빨강 아이콘으로 커짐 |
| 길안내 | 위쪽 어두운 카드에 다음 회전, 아래에 남은 거리·시간과 `119` |
| 도착 | "도착했어요. 이제 AED를 꺼내 주세요"와 할 일 4단계, `CPR 도와줘요` |

- **답은 흔들리지 않게**: 실제 도보 거리를 최대 1.5초 기다린 뒤 답을 한 번만 그리고, 늦게 온 결과로 답을 바꾸지 않습니다(숫자만 갱신).
- **확실히 열린 AED 우선**: 운영시간이 확인된 AED가 120초 이내로 더 멀면 그쪽을 먼저 고르고, 운영시간을 모르는 AED가 답이면 "확실히 열려 있는 AED도 있어요"를 함께 제안합니다.
- **색은 역할 하나에 하나**: AED는 빨강(`#E5304A`), 119는 먹색 버튼 + 빨간 전화 아이콘, 내 위치는 파랑, 나머지는 회색 단계. 지도 바탕은 채도를 60%로 낮춰 핀과 경로가 먼저 보이게 합니다.
- **AED | 대피소 전환**: 위쪽 버튼으로 모드를 바꾸며 기본은 AED입니다.
- **넓은 화면**: 900px 이상에서는 카드가 왼쪽 패널로 바뀝니다(발표·PC용).
- **바로가기**: 홈 화면 앱 아이콘을 길게 누르면 CPR 도우미로 바로 들어갈 수 있습니다(`?action=cpr`).

## 📌 주요 핵심 기능 (Key Features)

### 1. 실시간 자동심장충격기(AED) 정밀 탐색 & 개방 여부 판정
- **공공데이터포털 실시간 연동**: 국립중앙의료원 중앙응급의료센터 API를 실시간 호출하여 사용자 반경 내 AED 장비 정보 조회.
- **운영시간 기반 개방 여부 일원화 판정**: 요일별 운영시간(자정을 넘기는 야간 운영 포함)과 KST 현재 시각을 교차 분석하여 '지금 이용 가능', '이용 불가(영업 외)', '운영시간 정보 없음' 상태를 모순 없이 명확히 구분 표기.
- **건물 내부 상세 설치 위치 최우선 노출**: "관리사무소 1층 벽면", "6층 엘리베이터 앞" 등 상세 위치를 장소 이름으로 크게 보여줘 현장에 도착해 헤매지 않도록 함.

### 2. 지능형 3단계 위치 보정 & 데이터 정제 파이프라인
공공데이터의 필지 오차와 원천 좌표 오염을 원천 차단하기 위한 3단계 정밀 보정 시스템을 탑재했습니다:
- **1단계: 상세위치 기반 초정밀 세부위치 보정 (`Sub-location Calibration`)**:
  - `buildPlace`("관리사무소 1층", "101동", "별관", "경로당" 등)에서 세부 키워드를 자동 추출.
  - 아파트 단지 브랜드 일치(`verifyStrictBrandMatch`) 검증을 거쳐 단지 중심이 아닌 실제 관리동/세부 건물 위치로 핀을 초정밀 이전하고, 장소 자세히 보기의 '위치' 항목에 보정 내역을 표시.
- **2단계: 지번/필지 오차 지오코딩 보정 (`Building Geocoding`)**:
  - 70m 이상 편차 발생 시 공공데이터 지번 오차를 카카오 건물/도로명 정밀 실측 좌표로 보정.
- **3단계: 공공데이터 원천 좌표 오염 격리 및 광역 행정구역 교차 검증 (`Regional Cross-Validation`)**:
  - 텍스트 주소와 검색 지역의 광역 시·도(`sido`, `sigungu`) 교차 검증(`isRegionalConflict`). 충돌 시 바로 제외하지 않고 텍스트 주소 지오코딩으로 실제 위치를 검증하여, 시·도 경계 인근(대전-세종, 부산-양산 등)의 정상 시설은 유지.
  - 점진적 지오코딩(`Progressive Geocoding`)으로 시골/미등록 지번도 도로/읍면동 단위 좌표 확보. 단, 70m 단위 정밀 보정에는 건물 단위로 정확히 일치한 좌표만 사용하고, 도로·읍면동 단위 근사 좌표는 원천 오염 복원에만 사용하며 `위치 확인 필요`로 표시.
  - 5km 이상 괴리 발생 시 오염된 공공데이터 원본 좌표를 버리고 실측 주소 좌표로 강제 복원(`OUTLIER_RESTORED`)하며, 사용자 검색 반경(5km) 초과 시 자동 격리하여 타지역 유령 핀(예: 여주교도소 좌표 오염 사례) 원천 배제.

### 3. 초근접 마커 스파이더파이 (Spiderfier)
- **동일 건물/초근접(20m 이내) 핀 방사형 펼침**: 같은 건물이나 단지 내 복수 장비가 겹쳐 있을 때 클러스터 핀을 터치하면 방사형 다리(Spider Legs)로 펼쳐져 모든 장비를 개별 확인 및 선택 가능.
- **즉각적인 선택 인터랙션**: 펼쳐진 자식 핀 터치 시 즉시 해당 장비로 카드가 전환되며, 외부 터치 또는 클러스터 재터치 시 깔끔하게 축소 복귀.

### 4. PWA (Progressive Web App) 앱 설치 & 단독 창 실행
- **전 플랫폼 홈 화면/바탕화면 설치**: Android(Chrome, 삼성 인터넷), iPhone/iPad(iOS Safari 홈 화면 추가), PC(Windows, Mac Chrome/Edge) 지원.
- **단독 창(Standalone) 모드 구동**: 브라우저 주소창과 툴바 없이 네이티브 앱과 동일하게 독립 창으로 실행.
- **서비스 워커(Service Worker) 캐싱**: 설치 시 앱 화면 틀·아이콘을 미리 저장하고, 화면·API는 네트워크 우선(실패 시 저장본), JS·CSS는 저장본을 먼저 쓰고 뒤에서 갱신(Stale-While-Revalidate). 앱 코드까지 저장되는 시점은 **두 번째 실행**부터입니다.

### 5. 티맵(Tmap) 및 OSRM 보행자 최단 경로 및 실시간 길안내
- **티맵(SK Open API) 보행자 경로 안내(1순위)**: 국내 도로망, 골목길, 신호등 횡단보도, 육교, 지하보도 및 아파트/학교 단지 내 보행로를 정밀 반영하여 현실적인 도보 경로선(Polyline) 및 소요 시간 제공.
- **OSRM routed-foot 엔진 및 우회 트랩 방어(2순위 폴백)**: 오픈스트리트맵(OSRM) 보행망을 폴백으로 제공하며, 도로망 단절로 인한 비정상 우회 트랩(직선 600m 이내 2배 이상 우회)을 자동 감지하여 현실적 도보 계수로 보정.
- **보행 소요 시간 산출**: 보행 거리(m) 및 소요 시간(초/분) 제공, 카카오맵 길찾기 원터치 딥링크 연동.
- **실제 도보거리 기준 최단 시설**: 직선거리 상위 10개 시설의 실제 도보 거리를 계산해 다시 정렬. 여러 곳을 한 번에 계산해야 해서 대부분은 OSRM으로 계산하고, 직선으로 가장 가까운 1곳만 티맵으로 계산합니다. 그래서 첫 화면 시간과 안내 시작 후(티맵) 시간이 조금 다를 수 있습니다.
- **실시간 위치 추적 길안내**: 남은 거리·다음 회전 안내·도착 표시, 경로에서 50m 이상 5초간 벗어나면 현재 위치에서 자동 재탐색.
- **음성 안내**: "120미터 앞에서 우회전", "곧 좌회전", 도착 안내 (켜기/끄기 가능).
- **화면 꺼짐 방지**: 길안내·CPR 중에는 화면이 자동으로 꺼지지 않음 (Screen Wake Lock 지원 브라우저).

### 6. CPR 심폐소생술 105BPM 메트로놈
- 응급 상황 시 미국심장협회(AHA) 및 대한심폐소생협회 권고 템포(분당 100~120회)에 맞춘 105BPM 시각(깜빡임)·청각(비프음)·진동(안드로이드) 비트 가이드 제공.
- 오디오 시계에 박자를 미리 예약해 화면이 바빠도 박자가 밀리지 않으며, 30회 압박마다 인공호흡 2회 안내(교육받지 않은 경우 가슴압박만 계속).

### 6-1. 오프라인 대비
- **앱 실행**: 한 번 이상(앱 코드까지는 두 번) 온라인으로 열었다면 인터넷 없이도 열립니다.
- **마지막 결과로 안내**: 검색 결과를 **AED와 대피소별로 따로** 휴대폰에 저장해 두고, 인터넷이 끊기면 현재 GPS 위치 기준 거리·방향(예: "인터넷이 끊겨 마지막 결과를 보여드려요 · 남동쪽 125m")으로 다시 계산합니다. 마지막으로 찾은 곳에서 10km 이내일 때만 씁니다.
- **운영시간은 정직하게**: 저장 시점의 개방 정보는 지금과 다를 수 있어 24시간 시설만 '이용 가능'으로 표시합니다.
- **직선 방향 길안내**: 걷는 길을 받지 못하면 "남동쪽으로 걸어가세요"처럼 방위와 남은 거리로 안내하고 도착도 판정합니다.
- **항상 동작**: `119` 전화와 CPR 도우미는 인터넷이 필요 없습니다.
- **한계**: 카카오 지도는 오프라인에서 보이지 않을 수 있고(휴대폰에 남은 일부만 보일 수 있음), 한 번도 찾아보지 않은 지역은 찾을 수 없습니다. 다시 연결되면 최신 정보를 자동으로 다시 불러옵니다.

### 7. 민방위 대피시설 실시간 탐색
- **행정안전부 대피시설 공공데이터 연동**: 전국 18,800여 개소 민방위 대피시설 위치, 대피 면적(㎡), 지상/지하 층수 안내.
- **한국 위도 경도폭 보정**: 위도에 따른 경도 폭 `cos(위도)` 정밀 계산으로 동서쪽 시설 누락 원천 차단.

## 🛡️ 신뢰성 및 데이터 정제 원칙 (Reliability & Data Integrity)

본 프로젝트는 현장 응급 구조의 신뢰성을 최우선으로 하여 다음과 같은 데이터 정제 기준을 엄격히 준수합니다.

1. **서울시청 기본 좌표 오표기 및 비동기 레이스 컨디션 차단**:
   - Geolocation 위치 수신 전까지 임의 좌표를 사용하지 않으며, 위치 권한 거부 시 명확한 안내 문구를 표시합니다.
   - 요청 시퀀스 식별자를 통해 지연 응답이 최신 위치 데이터를 덮어쓰는 레이스 컨디션을 원천 차단했습니다.
2. **엄격한 다계층 위치 보정 및 오염 데이터 격리**:
   - 아파트 단지명 브랜드 검증(`verifyStrictBrandMatch`)을 통해 상가/타단지 오매칭을 방지하고, 상세위치가 명시된 경우에만 정확한 관리동으로 보정합니다.
   - 공공데이터 원천 데이터의 시·도 오기재는 광역 교차 검증을 통해 실측 주소지로 강제 복원 및 격리합니다.
3. **운영시간 판정 단일화 및 모순 제거**:
   - 요일별 시작/종료 시각을 단일 통합 함수(`calculateAedOperatingInfo`)에서 정규화하여 '24시간 상시 개방'과 '이용 불가'가 동시에 표시되는 논리적 모순을 0건으로 정제했습니다.
4. **출처 불명 및 허위·과장 문구 배제**:
   - 공인되지 않은 임의의 내구연한(8년 노후 판정 등) 및 출처 불명의 대표번호를 제거했습니다.
   - 공식 서비스 준비 중인 제보·점검 기능은 안내 모달을 통해 이용자에게 사실대로 투명하게 고지하며, 인증되지 않은 제보는 시설 추천·필터 판단에 반영하지 않습니다.
5. **데이터 출처 및 기준일 상시 공개**:
   - 오른쪽 위 안내(ⓘ) 버튼의 "세이프맵은 이렇게 만들어요" 창에서 국립중앙의료원, 행정안전부 등 데이터 출처와 기준일을 누구나 열람할 수 있습니다.

## ⚠️ 응급 상황 시 필수 주의사항 (Disclaimer)

> **심정지 및 생명 위급 상황에서는 반드시 `119` 신고가 최우선입니다.**

- 본 서비스의 AED 및 대피소 정보는 공공데이터포털(국립중앙의료원 중앙응급의료센터 및 행정안전부)에서 제공하는 원본 데이터를 바탕으로 제공됩니다.
- 시설의 내부 공사, 운영 정책 변경, 잠금장치 설치, 이전/철거 등으로 인해 실제 현장 상황과 일부 차이가 발생할 수 있습니다.
- 민방위 대피소는 전시·사변 등 국가 비상사태 시 주민 대피를 목적으로 지정된 시설이며, 평시 개방 여부는 시설 관리 주체(아파트, 상가, 지하철 등)의 운영 방침에 따릅니다.
- 길안내는 티맵 보행자 경로를 먼저 쓰고, 실패하면 OpenStreetMap 보행자 라우팅(FOSSGIS 정책에 따라 제공), 그것도 실패하면 직선거리 기반 추정 경로로 자동 전환(Fallback)됩니다.

## 🚀 로컬 개발 환경 설정 (Local Development)

### 1. 패키지 설치
```bash
npm install
```

### 2. 환경변수 설정 (`.env`)
프로젝트 루트 경로에 `.env` 파일을 생성하고 필요한 API 키를 입력합니다:
```env
KAKAO_MAP_API_KEY=your_kakao_javascript_key
KAKAO_REST_API_KEY=your_kakao_rest_api_key
DATA_GO_KR_KEY=your_data_go_kr_decoding_key
TMAP_API_KEY=your_tmap_app_key   # 없으면 OSRM으로 길안내
PORT=3000

# (선택) 위치 보정 결과 영구 캐시 - Upstash Redis / Vercel KV
KV_REST_API_URL=
KV_REST_API_TOKEN=
```
- **공휴일 판정**: 같은 `DATA_GO_KR_KEY`로 공공데이터포털의 `한국천문연구원_특일 정보` 활용 신청을 하면 공휴일을 API로 판정합니다. 신청 전에는 내장 공휴일 목록(2026~2027년)을 사용합니다. 공휴일에는 24시간 시설이 아니면 개방 여부를 "공휴일 운영 미확인"으로 표시합니다.
- **영구 캐시(선택)**: KV 환경변수를 설정하면 서버가 새로 떠도 위치 보정 결과를 재사용해 첫 조회가 빨라지고 카카오 API 사용량이 줄어듭니다. 설정하지 않으면 메모리 캐시만 사용합니다.

### 3. 로컬 서버 실행
```bash
# Vite 클라이언트 번들 빌드
npm run build

# Express 백엔드 및 정적 파일 서버 구동
node server.js
```
브라우저에서 `http://localhost:3000` 접속.

### 4. 테스트
```bash
npm test
```
운영시간 판정(야간·공휴일), 주소 비교, 시·도 검증, 거리 계산, 대피소 반경 탐색 등 핵심 로직을 검증합니다.
